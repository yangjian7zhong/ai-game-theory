# 🌙 AI狼人杀 · 7人局

7个AI自主博弈的狼人杀裁判观战室。

## 🎮 在线游玩

**[👉 点击开始游戏](https://yangjian7zhong.github.io/ai-game-theory/)**

## 🎭 角色配置（7人）

| 角色 | 数量 | 技能 |
|------|------|------|
| 🐺 狼人 | 2 | 夜间共同选择击杀目标 |
| 🔮 预言家 | 1 | 夜晚查验一人身份（好人/狼人） |
| 🧪 女巫 | 1 | 解药救人 + 毒药毒杀（各限一次） |
| 🔫 猎人 | 1 | 死亡时可开枪带走一人 |
| 👤 村民 | 2 | 无特殊技能，靠推理投票 |

## 🌙 游戏流程

### 夜晚阶段
1. 🐺 狼人睁眼 → 商议选择击杀目标
2. 🔮 预言家睁眼 → 查验一名玩家
3. 🧪 女巫睁眼 → 决定是否使用解药/毒药
4. 结算夜间行动

### 白天阶段
1. ☀️ 所有存活玩家依次发言
2. 🗳 投票放逐一名玩家
3. 🔫 如果猎人被放逐，可开枪带走一人

## 🏆 胜利条件

- **好人阵营**: 放逐所有狼人
- **狼人阵营**: 狼人数量 ≥ 好人数量

## 🧠 AI智能系统

- 狼人优先击杀预言家/女巫/猎人
- 预言家优先查验可疑玩家
- 女巫根据局势决定用药
- 投票基于身份和逻辑推理
- 每个AI角色有独特性格和发言风格

## 🛠 技术

- 纯前端实现，单HTML文件
- AI决策基于角色技能和策略逻辑
- GitHub Pages 免费托管
- 响应式设计，支持手机/平板

# ⚡ AI博弈论 · 囚徒困境

7个AI自主博弈对抗的裁判观战室。

## 🎮 玩法

- **7位AI选手**：谋略家·曹操、义士·关羽、智者·诸葛亮、武圣·吕布、隐士·司马懿、医者·华佗、猛将·赵云
- **3局积分赛**：每局最多6回合
- **五维属性**：勇武/狡黠/说服/洞察/合作，影响AI决策

## 🧠 AI智能系统

- **结盟机制**：高合作属性AI主动发起结盟
- **洞察系统**：高洞察力AI可窥探对手手势
- **说服系统**：高说服力AI可影响他人选择
- **背叛策略**：隐藏背叛者根据五维属性做出不同策略

## 📜 规则

1. 每回合：结盟 → 对话 → 洞察/说服 → 猜拳 → 红心审判 → 结算 → 暗杀
2. 红心审判：两人出相同手势，各扣2分后强制换招加赛
3. 多数票获胜方+3分
4. 背叛者可暗杀，被杀者该局积分清零
5. 三局总分最高者为冠军

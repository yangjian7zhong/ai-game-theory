## 🎭 核心机制

### 项圈系统
- 每人佩戴彩色项圈（红/金/蓝/绿/紫/粉/青）
- **普通人**能看到别人的项圈颜色，**看不到自己的**
- **内鬼**能看到**所有人**的项圈颜色（含自己的）

### 对话系统
- 每轮每人2次对话机会
- **私聊**：消耗1次，仅目标可见
- **公开喊话**：消耗2次，所有人可见

### 项圈投票（每轮结束）
- 每人投票猜自己的项圈颜色
- **猜对**：安全过关（终极对决时+1分）
- **猜错**：💥 自己爆炸死亡

### 终极对决（仅剩3人）
- 进入终极模式，界面特效变化
- 猜对+1分，猜错死亡不扣分

## 🏆 胜利条件

- **好人胜利**：连续4轮无人阵亡
- **内鬼胜利**：存活到最后 或 好人全灭
- **最终结算**：仅剩1人时统计总分，淘汰最后两名

## 🧠 AI智能系统

- 内鬼会伪装身份、混淆视听
- 好人通过项圈信息和对话推理
- 每个AI有独特性格和发言风格
- AI会根据局势调整策略
